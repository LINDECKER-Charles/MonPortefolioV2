Vérifier la connexion

Saisissez le code de votre application d’authentification ou un code de secours.

  1. Ajoutez un compte dans votre application d’authentification en scannant ce QR code.

    Si vous ne pouvez pas scanner le QR code, ajoutez la clé ci-dessous dans l’application, avec un code renouvelé toutes les 30 secondes.

  2. Saisissez ensuite le code à six chiffres pour confirmer l’activation.

Vérification en deux étapes

Le code est vérifié dès le sixième chiffre.

Conservez vos codes de secours

La vérification en deux étapes est activée. Chaque code permet une seule connexion si vous perdez l’accès à votre application. Gardez-les dans un endroit sûr : ils ne seront plus affichés après avoir quitté cet écran.
