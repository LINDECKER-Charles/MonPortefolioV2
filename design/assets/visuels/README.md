# Masters de la direction Lanterne

Production du **13 octobre 2026**, sur `feat/visuels-lanterne`, après validation du principe de la planche d’essai et autorisation de produire toute la série.

Les **74 illustrations uniques de méthode IMG** possèdent chacune un master de jour et une édition de nuit : **148 PNG**, dont les six masters de la planche d’essai. Les références réutilisées dans plusieurs fiches ne créent pas de doublons.

Les README des séries consignent les prompts réellement envoyés, les références jointes, les sources de génération, les corrections et les mesures. Les nuits proviennent d’éditions de leurs jours. Les retouches locales de position ont été autorisées ; elles sont détaillées pour chaque série.

Les PNG gardent la définition native du générateur, conformément à la règle des masters. Leurs ratios respectent la tolérance de 1 %. Les écarts de canevas de 1–2 pixels entre variantes ont été harmonisés en bord, sans redimensionnement global. Les fonds transparents restent transparents.

Le contrôle du noir utilise les pixels opaques (alpha ≥ 250) dont les trois canaux RVB sont ≤ 32 : les valeurs intermédiaires du grain et de l’anticrénelage ne sont pas quantifiées. Le noir strict `#000000` seul ne franchit pas systématiquement 70 %. L’édition générative conserve la composition mais peut redessiner certains contours : l’identité de tous les traits au pixel près n’est pas certifiée. Ces limites sont consignées pour la reprise technique des masters.

Les lanternes visibles ont été contrôlées par superposition avec la position de leur fiche, à ±3 points par axe. Les lanternes hors champ de `OMN-01` et `BLR-05` suivent leurs fiches.

Aucune séparation de calques ni commande de conversion exécutée pour cette production. Aucun fichier du site ni la commande de génération n’a été modifié. Les exports WebP et l’intégration restent à traiter séparément.
