## .NET

`dotnet.svg` vient du dépôt officiel [dotnet/brand](https://github.com/dotnet/brand), révision
`91845f6ddf2123b3bb1bfd1b6a386d9ce02b43aa`, chemin `logo/dotnet-logo.svg`.
Le fichier original est inchangé. Licence CC0-1.0 conservée dans `LICENSE-dotnet.txt` ;
les règles de marque et de représentation de .NET restent applicables.

Le même logo identifie l’écosystème pour les libellés `.NET`, `ASP.NET Core` et `SignalR`.
Il ne s’agit pas d’un logo dédié à ASP.NET Core ou à SignalR. L’icône `packageIcon.png`
du [dépôt officiel SignalR](https://github.com/SignalR/SignalR/blob/main/packageIcon.png)
est elle-même un symbole .NET ; aucun SVG distinct officiel n’a été identifié.

## GSAP

`gsap.svg` regroupe les deux SVG du wordmark dans `.header__logo-text`, affichés en
superposition dans l’en-tête du [site officiel GSAP](https://gsap.com/) le 2026-10-09.
Les quatre tracés sont conservés sans modification, dans leur `viewBox` original.
Empreinte SHA-256 : `7b9da3d23c9b3610e3bcbc2ed7e79fd21b83d79bffbe353a75c6e6cdd0b27e4e`.

Le site officiel indique « All rights reserved ». Aucune licence libre n’est annoncée pour
ce visuel : GSAP et son logo restent la propriété de Webflow. Le logo sert seulement à
identifier la technologie pratiquée, sans affiliation ni approbation supposée.
La [licence du logiciel GSAP](https://gsap.com/community/standard-license/) concerne le
logiciel ; elle n’est pas présentée comme une licence libre de ce logo.

Les tracés d’origine sont clairs. Le composant les inverse en mode jour et à l’impression,
et conserve sa couleur originale dans le mode nuit, y compris sans JavaScript.

## Composant

`site/src/components/parcours/LogoStack.astro` s’utilise avec `<LogoStack nom="Angular" />`.
Il affiche une icône décorative de 32 × 32 px : le parent doit toujours fournir le libellé
visible. Un nom inconnu fait échouer le build.

Noms pris en charge : Angular, TypeScript, C#, .NET, ASP.NET Core, SignalR, PostgreSQL,
MySQL, Git, GitHub Actions, Docker, Linux, Python, PHP, Symfony et Node.js.
S’ajoutent Tailwind CSS, GSAP, Java, Spring, Nginx, Apache, Ionic, Capacitor, Vitest et EF Core.
L’audit ajoute HTML, CSS, JavaScript, Bash, C, Express, SQLite, Playwright, ESLint, Prettier,
Twig, Doctrine, Leaflet, Caddy, Sass, RxJS, sharp, Rust, WebAssembly, Tauri, React,
Vite, Go, Vue.js, xUnit, PHPUnit, Trello, Photino.NET, FastAPI, pytest, Tokio, OpenTelemetry,
Prometheus, Karma, Jasmine, Pillow, API Platform, Spring Boot, GCC, Chart.js et MCP.
SQL, Axum, SQLx, Stockage S3 compatible, Dompdf, OpenTUI, Make, axe-core, Claude, Codex,
Kokoro et Piper affichent les
illustrations métier ci-dessus. Aucun outil de la page Compétences ne laisse de visuel vide.
